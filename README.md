### 🔬 Research

| Project | What it does | Paper | Code |
|---|---|---|---|
| **Neuro-Cardiac Multimodal Framework** 🏆 | Fuses ECG (CNN–BiLSTM), EEG (attention CNN) and clinical notes (ClinicalBERT) with attention-weighted fusion for early neuro-cardiac diagnosis (97.3% accuracy, AUC 0.985 vs 88.7–91.2% for single-modality models) — Best Paper Award | [IEEE GCWCN 2025](https://doi.org/10.1109/GCWCN66157.2025.11448396) | [Repo](https://github.com/velugurisaipavan/neurocardiac-multimodal) |
| **Deep PPG** | Activity-aware heart-rate estimation from wrist-worn PPG + accelerometer spectra: a Random Forest predicts the wearer's activity and feeds a CNN (7.33 ± 1.15 BPM MAE on PPG-DaLiA vs 7.65 ± 4.20 for the reference model) | [IEEE ICAET 2025](https://doi.org/10.1109/ICAET63349.2025.10932185) | [Repo](https://github.com/velugurisaipavan/deep-ppg-activity) |
| **ConvAttRecurNet** | Hybrid CNN + BiLSTM + attention model that detects suicidal ideation in social-media text (94.06% test accuracy, AUC 0.986 on 232K Reddit posts) | [IEEE ICDT 2025](https://doi.org/10.1109/ICDT63985.2025.10986603) | [Repo](https://github.com/velugurisaipavan/Convattrecurnet) |
| **Ensemble Confidence & Active Learning** | Deep ensembles, SWAG/MultiSWAG and active learning to improve calibration and accuracy on MNIST and MURA | IEEE ICCMN 2026 (accepted) | — |
| **Real-Time Neuro-Cardiac Monitoring** *(in progress)* | Unifies Deep PPG and a multimodal neuro-cardiac model into an edge-deployable wearable monitoring framework | Manuscript in preparation | — |
